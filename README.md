# צוות השחר: האתר ללקוחות

האתר הציבורי של Dawn Crew בכתובת https://thedawncrew.com . מטרייה אחת, שלושה קווים, וכל קו במיתוג שלו:
- **GROOT** (הילה): כחול כהה ותכלת, הלוגו ב-`assets/groot-logo.svg`.
- **דפי** (אדוה): עוד אין מיתוג. כרגע צבעי placeholder ב-`site.css` (`--dafi-*`).
- **OZER** (טל): פטרול ופליז, Suez One לכותרות, Assistant לטקסט, Azeret Mono למספרים.

## איך עובדים
- כל push ל-`main` עולה לאוויר אוטומטית תוך דקה (Vercel מחובר לריפו מ-10.10).
- כל branch אחר מקבל כתובת תצוגה משלו. מומלץ לעבוד ב-branch ולמזג ל-`main` כשמוכן.
- אתר סטטי: HTML ו-CSS בלבד, בלי build. `index.html` הוא דף הבית, `site.css` העיצוב.
- הריפו ציבורי. **אסור** להכניס לכאן סיסמאות, מפתחות, מחירים פנימיים, או מידע על לקוחות.

## מה כבר מחובר (ב-`vercel.json`, לא לגעת בלי טל)
- `/q/...` (הצעות מחיר) ו-`/p/...` (הצעות ללקוחות) מגיעים מהאתר הפנימי, כדי שלינקים שכבר נשלחו ימשיכו לעבוד.
- `/groot/magazine/` מציג את המגזין של הילה (groot-magazine.netlify.app). הילה ממשיכה לעדכן אצלה.
- `/ozer/magazine/` המגזין של OZER, בתוך הריפו הזה.
- `/team` ו-`/d/...` מפנים לאתר הפנימי ב-backoffice.thedawncrew.com.
